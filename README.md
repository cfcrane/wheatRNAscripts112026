The scripts in this tar archive were used during data analysis of an RNA-seq experiment involving greenbug biotypes B and H on 
Newton wheat.  Half of the aphids carried Cereal Yellow Dwarf Virus.  Wheat leaves were sampled before infestation and 1, 2, 3, 5,
10, 15, and 20 days thereafter.  The "adhoc" scripts are generally very specific, while the other scripts are more parameterized
and portable.
